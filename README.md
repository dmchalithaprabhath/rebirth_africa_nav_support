# Rebirth Africa Nav – Support Page

Minimal support page for App Store Connect **Support URL** and GitHub Pages.

## Contents

- **index.html** – Main page (app name, tagline, support email)
- **styles.css** – Theme colors from the app (primary blue, orange accent)
- **logo.png** – Copy from `rebirth_africa_nav/assets/branding/logo.png` into this folder if not already present

## Publish on GitHub Pages

1. Create a new repository (e.g. `rebirth-africa-support`).
2. Copy everything in this folder (including `logo.png`) into the repo root.
3. GitHub → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** (or **master**) → **Save**.
4. Your Support URL will be: `https://YOUR_USERNAME.github.io/REPO_NAME/`

Use that URL in App Store Connect as the **Support URL**.
